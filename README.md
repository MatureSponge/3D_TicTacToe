# 3D_TicTacToe
A console game of 3D_TicTacToe made with Java.

3D TicTacToe is basically a 3x3 TicTacToe plate stacked. (look image)
- 27! total cases

The regular minimax algorithm for 3x3 TicTacToe does not work in this version, because there are too many cases. 
I optimized it through immediate win case detection, alpha/beta pruning, and depth heuristics.
